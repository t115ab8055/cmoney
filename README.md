# CMoney 股市爆料同學會爬蟲

使用 Python 與 Playwright 開啟個股討論區，切換為「最新」排序並捲動頁面，從文章 API 回應整理資料，以文章 ID 去重後匯出 JSON 與 CSV。

## 安裝與執行

環境需求：Python 3.14 以上、uv 與 Playwright Chromium。瀏覽器以無頭模式（`headless=True`）執行，不顯示視窗，無需桌面環境。

在專案根目錄執行：

```bash
uv sync
uv run playwright install chromium
uv run python main.py
```

預設股票為 `6214`、`2317`，可修改 `main.py` 的股票清單。程式遇到早於 2026 年的文章便停止擷取；年份門檻設定於 `parse.py`，時間使用執行電腦的本地時區。

## 輸出資料

- `output/{股票代碼}.json`：以文章 ID 為鍵，保留結構化資料。
- `output/{股票代碼}.csv`：中文欄位、UTF-8 BOM 編碼，可供 Excel 開啟。

內容包含文章與作者 ID、建立時間、標題、標記股票、文章內文、贊助 P 點、評論數及七種表情回應數。僅收錄評論數，不包含評論內文；重跑會覆寫同名輸出檔。

## 檔案結構

| 檔案 | 用途 |
| --- | --- |
| `main.py` | 瀏覽器操作、監聽 API 回應與擷取流程 |
| `parse.py` | 文章欄位解析、時間篩選與表情統計整理 |
| `export.py` | JSON、CSV 匯出 |

## 目前限制

- 尚未處理空資料或無新回應時的停止條件；若未遇到年份門檻，可能持續捲動。
- 標記股票的 `name` 目前固定為 `0`，尚未解析股票名稱。
- 擷取依賴網站介面與 API 格式，現有輸出不代表已完整收錄指定年份的文章。
